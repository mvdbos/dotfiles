description: Interview about a plan or design while updating the domain glossary and selectively recording ADRs. Use when the user wants grilling with domain documentation.
disable-model-invocation: true
---

1. For the requested interview, read `~/.config/opencode/references/grilling.md` (resolve `~` to the user's home directory for file tools) and apply it to the requested scope.
2. Load `domain-modeling` to maintain the glossary and selectively record durable decisions as ADRs as answers settle.
3. Finish with the confirmed decision summary and links to changed documents. A complete spec is a separate output produced by `to-spec` when requested.
